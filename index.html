Paragraph text with a link that launches in a new tab: MDN JS.
JS automatically finds external link and applies the .links__external helper class along with necessary screen reader text notifying the user that a link is external and/or opens in a new tab (to meet WCAG 2.1 AA link requirements and best practices). The JS will decorate external links the same way in localhost and CloudCannon to ensure an accurate preview when published to kcc.edu.

Double hyphens are automatically converted to em-dashes using JS -- like this. Triple hyphens (---) are left alone.
If you need to keep the double hyphens as-is (like in code examples) escape it using a backslash: 

        .positioning\--max-width-600 {
          max-width: 600px;
          margin-left: auto;
          margin-right: auto;
        }
